# IQ Tester

A timed quiz in the browser. Thirty questions, five in each of six categories, with twenty minutes on the clock. When the test ends, the results screen shows the score, a bell curve, and a breakdown by category. Past attempts stay in `localStorage`. No install and no server.

## Categories

- Pattern recognition
- Logical reasoning
- Spatial awareness
- Numerical ability
- Verbal intelligence
- Memory and attention

## Files

| File | Role |
| --- | --- |
| `index.html` | Screens |
| `css/styles.css` | Layout |
| `js/questions.js` | Question bank |
| `js/engine.js` | Timer, question order, and recorded answers |
| `js/results.js` | Score, charts, and saved history |
| `js/app.js` | Screen navigation |

## Run it

Open `index.html` in a browser.
